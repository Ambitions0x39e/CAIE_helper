# CIE Helper

Local-first past paper tracker for CAIE students.  
Download papers, send to GoodNotes, log scores, track progress.

---

## Setup
1. Install uv
   
2. Clone this repository and `uv sync`

3. Copy .env file `cp .env.example .env`

---

## Execution

You could execute it with `uv run streamlit run app.py`
