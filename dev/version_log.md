## v1.1.3 — 2026-07-28

**主题：自动更新 feature**

对应 commit：`2d4361e` + `b6f1e70`；安装器 `dist/cie-helper-1.1.3-setup.exe`。

### 新增

- **应用内自动更新**：以前出新版本得自己去 GitHub 翻发布页、下安装包、再手动装一遍。现在「设置 → 关于 → 更新」一键走完 —— 点一下查最新发布，有新版本会先弹窗告诉你版本号和这一版改了什么，你点「立即更新」才开始下载；装的时候不再弹安装向导，应用会自动退出让安装程序覆盖自己，装完重新打开就是新版。已经是最新版本、或者查询失败，都会明确告诉你一声，不会点完静悄悄什么都没发生。

### 行为变更

- **只在你点「更新」时才联网查版本**，启动时不做后台检查 —— 不想被打断就别点它。
- **查到新版本不会自动装**：一定先弹确认框给你看版本号和更新说明。「静默」只是指装的过程不弹安装向导，不是不问你就动手 —— 你正用着应用，不能被无声关掉。
- **只装当前系统的包**：Windows 认 `.exe`、macOS 认 `.pkg`，按当前系统自动挑，绝不会下错平台的安装包；线上版本号不比本机新时一律当作「已是最新」，不会往回装旧版。没有对应安装包的平台（如 Linux）点「更新」会直接打开 GitHub 发布页，不报错也不崩。

### 其他

- 新增 53 个自动更新相关测试（版本比较、平台与资产选择、超时与 HTTP 错误、两个平台的安装命令逐字比对），全部离线运行，不打网络也不真装东西。
- 修好一个长期失败的测试：「批改凭证未配置时应返回空」此前直接读本机 `~/.cie_helper/.env`，于是在任何真配过 key 的机器上都会失败 —— 它测的是环境而不是代码。现在测试自己造出「未配置」的环境，并补上了反向用例。测试套件从 177 通过 / 1 失败变为 **179 通过 / 0 失败**。
- 消除每次跑测试都会打印的一条 asyncio 警告（`Task was destroyed but it is pending!`）：测试收尾没等取消完成，与产品代码无关。

## v1.1.2 — 2026-07-27

**主题：小题题干归位 + 设置页可用性修复**

安装器：`dist/cie-helper-1.1.2-setup.exe`（Windows，56 MB）。本次发布同时包含 v1.1.0 与 v1.1.1 的全部改动。

### 修复

- **小题题干不再被上一题吞掉**：像「(b) 铬的简写电子排布是 [Ar] 3d⁵4s¹」这类挂在字母层的题干，此前会被裁进上一小题，轮到 (b)(i) 时反而看不到 —— 而这句正是答题必需的前提。现在每个字母的首个罗马小题从字母标记处起裁，题干归位（与 v0.2.0 修的大题题干是同一条规则）。9701 上影响 4 处。
- **macOS 图标比别的应用大一圈**：图形此前按满画布 1024 导出，而 macOS 自 Big Sur 起要求 1024 画布内图形本体为 824、四周各留 100px，因此它在 Dock 里比原生图标大 1.24 倍。已按规范单独出一份 macOS 图标（形状不变，仅尺寸归位）；Windows 图标沿用原样，不受影响。

### 新增

- **设置页改版**：原来是一屏平铺全部凭证的长表单，现在改成条目式菜单 —— 点「SMTP / GoodNotes」「Grader API」「关于」进入各自子页面，有原生的滑入动画、顶栏返回按钮和 iOS 边缘滑动返回。每个子页面独立读取与保存，互不影响。
- **关于页**：显示应用图标、名称与版本号，并提供「反馈」入口直达 GitHub Issues。

### 行为变更

- 上述题干归位会让**所有卷子**的裁剪范围略有变化：每个字母的首个罗马小题往上多含一段题干，对应上一小题少含同样一段。识别率不受影响（9701 / 9702 / 9700 / 9231 / 9618 实测均维持满匹配）。
- **设置项排版**：每项设置为一行，名称居左、输入框居右，行间以细分隔线区隔；窗口较窄（手机、分屏）时自动改为名称在上、输入框占满整行。原先输入框自带的浮动标签已移除，改由行左侧统一承担，框内留示例值作提示。
- **保存按钮拆分到各子页面**：原先一个「保存」同时写入邮件与批改两套凭证，现在各子页面各存各的。

## v1.1.1 — 2026-07-27

**主题：化学卷题目裁剪错位修复**

未单独出安装器，随 v1.1.2 一并发布。

### 修复

- **罗马小题裁剪整体错位**（接 v1.1.0）：化学卷等含 `(iv)` 小题的卷子，同一 (a)/(b) 下的每个罗马小题都会被裁到**上一小题**的位置 —— AI 拿到的是前一题的作答，给分自然全错。9701 上表现为 Q1(a)(ii) 被按 (i) 的答案评、(iii) 被按 (ii) 的答案评。根因是识别罗马标记时只认得 `i` 这个字形，`(iv)` 里的 `v` 从未被学到，导致全卷 `(iv)` 标记被丢弃，后续定位连锁错位。现已修正，Q1(a) 四个小题裁剪区逐个渲染核对无误。

## v1.1.0 — 2026-07-27

**主题：化学卷（9701）批改流程修复**

未单独出安装器，随 v1.1.2 一并发布。

### 修复

- **化学卷题目页码自动识别**（本版核心）：9701 化学卷此前 42 道小题只能自动识别出 4 道（每道大题只中第一小题），其余全部要手工填页码，批改流程基本不可用。根因是识别乱码字体卷子时的一个判定条件对化学卷不成立，导致整条小题识别逻辑停摆。现已修正，**9701 实测 42/42 全部识别**；物理（9702）、生物（9700）、数学（9231）、计科（9618）各卷识别率不变，无回退。
- **评分标准封面信息读取**：化学卷的评分标准封面文字排布特殊，导致试卷编号和总分读不出来，界面显示成「已解析: (42 题), 0 总分」。现在能正确显示（9701 为 `9701/23/O/N/25`、60 分）。本地 68 份评分标准全部读取正确。
- **旧解析结果自动修复**：此前已解析过、缓存里缺试卷编号/总分的卷子，再次打开时会自动补全这两项，无需重新解析（不消耗 API 额度），题目内容原样保留。

### 其他

- 新增 9 个测试覆盖上述两处修复，并修正了 3 个旧测试中对乱码卷子的错误假设。

## v1.0.0 — 2026-07-21

**主题：批改可靠性大修 + 界面重构（首个正式版）**

安装器：`dist/cie-helper-1.0.0-setup.exe`（Windows）、`dist/cie-helper-1.0.0.pkg`（macOS）。

### 修复

- **AI 批改不再卡死**：批改扫描件/大体积答卷时会无限卡住、拿不到结果的问题已根治。渲染改为在本机进程内完成，不再受内部传输瓶颈限制；批改与 API 调用都加了超时，即使出错也会明确提示而不是无限等待。
- **题目页码自动识别准确率大幅提升**：此前物理/生物等科目的很多小题（尤其 (b)(c) 及 (i)(ii)(iii) 罗马小题）页码识别不全，导致这些题被漏批。现在能正确识别乱码字体卷子的各级小题。
- **识别结果不再虚报**：以前界面会显示「已识别 30/30 题」但实际一大半无法批改。现在如实显示可用题数，并点名需要手动补页码的题目，对应输入框标橙色提示。
- **批改失败有持久提示**：批改出错时改为在页面上常驻红色横幅说明原因（含出错题号），不再是一闪而过的浮层。

### 新增

- **同时只允许一个批改请求**：批改进行中重复点击会提示等待，不会堆叠任务。
- **macOS 安装包（.pkg）**：安装后可直接打开，免去 Gatekeeper 手动放行的额外步骤。
- **设置独立成标签页**：原顶栏齿轮里的 SMTP / GoodNotes / Grader API 配置移到底部「设置」标签页。
- **顶栏「登记成绩」按钮**：随时为待完成的试卷手动登记分数。

### 行为变更

- **统计页弹性布局**：窗口够宽时成绩表格在左、趋势图在右；窗口窄时趋势图占满上方、表格在下。
- **解析新评分标准时**：会先收起当前的选题界面再显示加载条，不再把加载条埋在页面底部。
- **中文显示修复**：修复 Windows 上中文显示成日文字形的问题（各平台使用对应的简体中文系统字体）。

## v0.2.0 — 2026-07-17

**主题：Mark 标签页批改流程修复（题目检测不全 / 缓存陷阱 / 题干裁剪）**

对应 commit：`389048f`；安装器 `dist/cie-helper-0.2.0-setup.exe`（48 MB）。

### 修复

- **评分标准起始页自动检测**（此前的核心 bug）：原来固定默认从第 6 页开始解析评分标准，但实际首个内容页因科目而异（本地 67 份 MS 实测 2–8 页都有，53 份不是第 6 页）。9618 等从第 3 页出题的科目会整段丢失前几题（表现为「答卷分割从 Q2(iii) 才开始」——其实是题目清单本身就缺）。现在扫描「Question / Answer / Marks」表头 + 封面后首个无文字（扫描图）页自动定位，宁早勿晚。
- **题干不再被上一题吞掉**：题目分割时，每个大题的第一个子题现在锚定到主题号（"2"）位置而不是 "(a)" 标记位置，题目引言/图表落在自己的裁剪区里（AI 批改能看到题目上下文），不再被并进上一题的最后一个子题。
- **解析缓存按起始页区分**：MS 解析缓存的 key 现在包含解析用的起始页（`*.spN.json`）。此前改了起始页重新解析会静默命中旧缓存，怎么改都没效果。旧版无后缀缓存自动失效、下次重解一次。

### 新增

- **缓存提示 + 重新解析**：解析结果来自缓存时，「解析评分标准」按钮同行右侧显示淡黄色提示框「此结果来自缓存」，附「重新解析」按钮强制跳过缓存重跑 VL 解析。
- **起始页输入框改为可留空**：留空 = 自动检测（推荐）；填数字 = 手动覆盖。

### 其他

- 新增 13 个测试（起始页检测 / 缓存 key / 主题号锚定）。

## v0.1.0 — 2026-04-01 起 【alpha 版本】

初始形态到可安装桌面应用的全部演进，未做正式版本切分，统记为 alpha。

- **核心三件套**（Streamlit）：Download（CIEFrank / PapaCambridge 下载真题）、Manage（做题记录 CSV 库、交分、发送 QP 到 GoodNotes 邮箱）、Analytics（按科目 / paper type 的成绩趋势）。
- **AI 批改（Mark 标签页）**：VL 模型解析评分标准（含纯图片页）→ 答卷按题自动分割裁剪 → 逐题批改给分；MCQ 卷支持 VL 识别学生答案自动对分。
- **Streamlit → Flet 迁移**：为 iOS / 桌面打包重写 UI；渲染层从 fitz → pdfplumber → 原生 pdfrx Dart 扩展（`flet-pdf-render`），分割改用 pdfminer.six（纯 Python，iOS 安全）。
- **Windows 打包**：`flet build windows` + Inno Setup 安装器（per-user 免 UAC）、CIE 字标图标；体积从 1.2 GB 治理到 190 MB（exclude 列表）、flet 三件套版本锁定修复白屏。
- 附属工具：GT Checker（分数线查询 + 批量下载）、syllabus 配置管理页。
